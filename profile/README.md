# Contextory

1С умеет прятать важное. Мы делаем инструменты, которые помогают это находить и связывать с кодом.

Сейчас здесь открыт [Ordinary Form Decoder](https://github.com/contextory/ordinary-form-decoder) — разборщик обычных форм 1С для анализа через [rlm-tools-bsl](https://github.com/Dach-Coin/rlm-tools-bsl). Другие проекты появятся по мере готовности.

Проекты ведёт [synklair](https://github.com/synklair) при участии OpenAI Codex.
